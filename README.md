# Driveway Gloss: mobile car wash & polishing website

A complete website for a mobile car detailing business, built as a single HTML file.

**Live demo:** https://awmirdeathnotes-bit.github.io/Driveway-gloss/

## Features

- Booking in four steps: services, date and time, customer details, payment
- 10% online deposit, with the option to pay more online and the rest by cash or card on the day
- Service-area check with an adjustable radius (25 miles by default) and optional travel fee
- Customer area to reschedule, cancel, pay the balance and view receipts
- Owner dashboard: calendar schedule, day route, booking editor, payment collection
- Automatic accounting with Excel export
- Blog posts, partner coupons, promo codes, shop products, membership plans
- Social media links and a WhatsApp button
- Six colour themes plus custom colours, with dark mode support
- Works on mobile, tablet and desktop

## Trying the demo

Use the **Customer view / Owner view** switch in the bottom-left corner to explore both sides.
This demo keeps data in memory only, so refreshing the page resets it.
The card form accepts test card `4242 4242 4242 4242` with any future expiry date and any CVC. No payment is taken.

## Built with

HTML, CSS and vanilla JavaScript in one file. Uses Google Fonts and SheetJS for the Excel export.
